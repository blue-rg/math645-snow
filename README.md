# 비례식 픽셀 눈싸움 — 깃허브 페이지 + 파이어베이스 실시간판 설치 방법

6-2 4단원 5차시 「비례식의 성질을 알아봐요」(교과서 86~87쪽, 수학익힘 62~63쪽) **픽셀 2D 횡스크롤 눈싸움**이에요. 게임 화면은 **깃허브 페이지(GitHub Pages)** 에 올리고, 실시간 대전·코인·기록은 **파이어베이스 Realtime Database** 로 주고받아요. 둘 다 무료 계정으로 돼요.

## ⚡ 3D 「비례식 눈싸움」을 이미 설치했다면 (5분)
같은 파이어베이스 프로젝트를 그대로 써도 돼요. 이 게임은 데이터베이스의 `snow/px/` 아래에 따로 저장해서 **3D 게임과 방·코인·기록이 섞이지 않아요**(규칙도 바꾸지 않아도 돼요).
1. 3D 게임 저장소의 `firebase-config.js` 를 이 폴더의 `firebase-config.js` 자리에 **그대로 복사**해요.
2. 아래 5~6단계처럼 **새 저장소**(예: `pixel-snowball`)를 만들어 이 폴더 파일을 올리고 깃허브 페이지를 켜요.

## 폴더에 든 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 화면 (고치지 않아도 돼요) |
| `firebase-config.js` | **선생님이 채우는 파일** — 파이어베이스 연결 정보와 선생님 비밀번호 |
| `lib/` | 파이어베이스 9.23.0(Apache-2.0) 도구와 라이선스. 그림 도구는 따로 필요 없어요(캔버스로 직접 그려요). |
| `database.rules.json` | 데이터베이스 규칙(3단계에서 붙여넣기) |
| `README.md` | 이 설명 |

## 처음 설치한다면
### 1. 파이어베이스 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **프로젝트 추가(만들기)** → 이름 예: `snowball-604` → (구글 애널리틱스는 꺼도 돼요) → 만들기.

### 2. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드(Build) → Realtime Database** → **데이터베이스 만들기**.
2. 위치는 가까운 **싱가포르(asia-southeast1)** 를 골라요.
3. 보안 규칙은 **잠금 모드**로 시작해요(다음 단계에서 바꿔요).
4. 화면 위에 나오는 주소(예: `https://snowball-604-default-rtdb.asia-southeast1.firebasedatabase.app`)가 **databaseURL** 이에요.

### 3. 규칙 넣기
Realtime Database의 **규칙** 탭에서 내용을 모두 지우고 `database.rules.json` 내용을 붙여넣은 뒤 **게시**해요.
```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "snow": { ".read": true, ".write": true }
  }
}
```
- 게임 자료는 모두 `snow` 아래(이 게임은 `snow/px`)에만 저장돼요.
- ⚠️ 로그인 없이 쓰는 게임이라, 게임 주소를 아는 사람은 `snow` 아래 자료를 읽고 쓸 수 있어요. 주소는 우리 반에만 알려 주세요.

### 4. 웹 앱 등록하고 설정값 복사하기
1. 왼쪽 위 **⚙️ → 프로젝트 설정** → 아래 **내 앱**에서 **웹(`</>`)** 아이콘.
2. 앱 닉네임(예: `눈싸움`) → **앱 등록** (Firebase 호스팅은 체크하지 않아요).
3. 나오는 `const firebaseConfig = { ... }` 안의 값(apiKey, authDomain, databaseURL, projectId …)을 복사해요.
4. `firebase-config.js` 를 열어 `window.FIREBASE_CONFIG = { ... }` 안을 복사한 값으로 바꾸고, `window.TEACHER_PIN = '4826';` 처럼 선생님 비밀번호를 정해요.

### 5. 깃허브 저장소에 올리기
1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**.
2. 이름 예: `pixel-snowball` · **Public** → **Create repository**.
3. **uploading an existing file**(또는 **Add file → Upload files**)을 눌러 **`index.html`, `firebase-config.js`, `lib` 폴더(통째로), `database.rules.json`, `README.md`** 를 끌어다 놓고 **Commit changes**.
   - `lib` 폴더 안 파일 3개가 `lib/` 아래에 올라갔는지 확인해요.

### 6. 깃허브 페이지 켜기
1. 저장소 **Settings → Pages** → **Source: Deploy from a branch**, **Branch: main / (root)** → **Save**.
2. 1~3분 뒤 나오는 주소 **`https://내아이디.github.io/pixel-snowball/`** 가 학생에게 나눠 줄 게임 주소예요.
3. 첫 화면에 "⚠️ 온라인 대전 준비가 덜 됐어요"가 보이면 `firebase-config.js` 값을 다시 확인해 주세요.

## 수업에서 쓰는 법
1. 학생은 **이름**과 **반 코드**(예: `옥정초604`)를 쓰고 **⛄ 친구와 온라인 눈싸움** → **🎲 빠른 매칭**(또는 방 만들기·방 번호 입력).
2. **6명이 되면 바로**, 2~5명이면 **2명이 모인 때부터 20초 뒤 자동** 시작. 방장(👑)은 **▶ 지금 시작**.
3. 한 판은 **4분**. 결과 화면에 순위·점수·**받은 코인**·틀린 문제 풀이가 나와요.
4. 첫 화면 **🛠️ 장비 강화**에서 코인으로 장비를 올려요. 코인은 **이름+반 코드**로 저장돼요(3D 눈싸움 코인과는 따로예요).
- 남는 학생은 **🤖 컴퓨터와 연습**(코인 조금, 하루 100코인까지).

## 🗺️ 눈밭과 🐉 서리용
- 판마다 눈밭이 달라요. 언덕 사이에 **탑과 굴 · 골짜기 다리 · 눈 요새 · 하늘 계단 · 트램펄린 · 빙판** 구역이 섞여 나오고, 하늘은 **낮 · 노을 · 오로라 밤** 중 하나예요(대전하는 모든 기기에 같은 눈밭).
- 얼음 발판은 **2칸씩 계단처럼** 놓여 있어 밟고 위로 올라갈 수 있어요(점프 높이 약 2.9칸). 🔴 트램펄린은 약 7칸 높이로 튀어 올라요. 빙판은 미끄러워요.
- **서리용 냉기바람**: 40초부터 35초마다(40·75·110·145·180·215초) 눈밭 가운데(높이 7.5칸)를 기준으로 **위쪽 또는 아래쪽 절반**에 7초 동안 바람이 불어요. 3초 전에 서리용이 나타나 알려 줘요.
  - 바람 속에서는 **달리기가 절반으로 느려지고, 1초마다 체력 4**가 닳아요(방패가 먼저 닳고, 체력 1 아래로는 내려가지 않아서 바람만으로 꽁꽁이 되지는 않아요).
  - 아래쪽 바람이면 발판을 밟고 위로, 위쪽 바람이면 아래로 내려가 피해요.

## 게임 규칙·코인·장비 (3D 눈싸움과 같은 규칙 코드 + 냉기 피해)
- 정답 ⭐ ⚪+2 · ⭐⭐ ⚪+3 · ⭐⭐⭐ ⚪+4(최대 12) · 눈덩이 한 개 20 피해 · 체력 0이면 3초 꽁꽁 후 다시 뛰기(탈락 없음, 2초 보호)
- 점수 = 명중×10 + 꽁꽁×30 · 연속 3정답 아이템(🛡️ 방패 · ☕ 회복 · 🌕 왕눈덩이 · 🛷 썰매 신발)
- 순위 코인(4명: 100/70/45/25) + 정답×2(최대 20) · 중간에 나가면 0
- 장비 5종×3단계(100/250/500코인): 🧤 장갑 · 🧥 패딩 · 👢 부츠 · 🎒 가방 · ❄️ 장인

## 👩‍🏫 선생님 메뉴 (첫 화면 맨 아래)
- **📥 대전 기록 내려받기**(CSV) · **대전 기록 초기화 / 코인·장비 초기화**(두 번 눌러야 지워지고, 지우기 전 CSV가 먼저 내려받아져요) · **지난 대전 방 정리**(수업이 끝난 뒤).
- 코인을 직접 고치려면 파이어베이스 콘솔 → Realtime Database → `snow/px/wallets/반 코드/이름` 의 `coin`, `up` 값을 고쳐요.
- 비밀번호는 `firebase-config.js` 에 적혀 있어서 완벽한 잠금은 아니에요.

## 실시간 대전의 한계
- 친구 움직임은 **약 0.45초 전** 모습으로 보여요. **명중은 던진 사람 화면에서 판정**해서, 맞은 학생은 "피한 것 같은데 맞았다"가 가끔 있어요. 체력·점수·코인은 데이터베이스 한 곳에서 정해서 모든 기기의 결과는 같아요.
- 학교 인터넷에서 `*.firebasedatabase.app`, `*.firebaseio.com` 이 막혀 있으면 온라인 대전이 안 돼요. 수업 전에 2~3명이 먼저 시험해 보세요.
- 무료(Spark) 요금제 한도: 동시 연결 100개, 저장 1GB, 한 달 내려받기 10GB(https://firebase.google.com/pricing 기준, 바뀔 수 있어요). 실제 사용량은 콘솔의 **사용량** 탭에서 확인해요.

## 연결이 안 될 때
- 카카오톡·네이버 앱 안에서 열었으면 **다른 브라우저(크롬·사파리)로 열기**.
- "20초 안에 파이어베이스 응답이 없어요" → databaseURL, 규칙 **게시** 여부 확인. "permission denied" → 3단계 규칙이 게시되지 않은 거예요.
